# SIATRAB – Sistema de Apoio ao Trabalhador

Este repositório contém o código-fonte e a documentação do sistema **SIATRAB**, desenvolvido como **Trabalho de Conclusão de Curso (TCC)** no curso de **Tecnologia em Sistemas para Internet** no Instituto Federal de Brasília (IFB).

O projeto tem como objetivo apoiar trabalhadores na compreensão de seus direitos trabalhistas e na conferência de cálculos relacionados a verbas rescisórias e outros benefícios, por meio de uma plataforma digital de caráter educacional e informativo.

## 🚀 Sobre o Projeto

O SIATRAB busca traduzir a complexidade da legislação trabalhista para uma interface intuitiva, permitindo que o usuário realize simulações de cálculos e entenda melhor os termos jurídicos envolvidos no encerramento de vínculos empregatícios.

### 🛠 Tecnologias Utilizadas

- **Framework:** Flutter
- **Linguagem:** Dart
- **Plataforma:** Web / Mobile

## ⚖️ Finalidade do Projeto

O sistema possui finalidade exclusivamente acadêmica e educacional, não substituindo a atuação de profissionais especializados, como advogados, contadores ou órgãos oficiais.
